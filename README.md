Pagina wwb responsive:
Objetivo:
Desarrollar una página web responsive a partir de una maqueta visual proporcionada por la cátedra,
aplicando de manera práctica los conceptos de estructura semántica con HTML5, estilos mediante CSS3 y componentes responsive utilizando el framework Bootstrap 5.
Respetando la estructura general, distribución de elementos, jerarquía visual y comportamiento responsive solicitado.
